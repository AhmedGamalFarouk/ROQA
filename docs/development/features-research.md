# Features Research: AI Meter, Native Materials, and Lock State

## 1. AI Subscription Usage Meter
- **Claude (Pro/Max & Claude Code):** No official, documented way to read consumer subscription quota or reset time ([Anthropic Rate Limits](https://docs.anthropic.com/en/api/rate-limits)). Admin API covers developer Console spend/RPM, not consumer tiers. `~/.claude/settings.json` stores local configuration only ([Claude Code Docs](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview)). The CLI's interactive `/usage` command queries internal, undocumented endpoints. Querying private endpoints or scraping `claude.ai` breaches ToS §3.2 ([Anthropic Commercial Terms](https://www.anthropic.com/legal/commercial-terms)). Auth: Admin key for API; none for subscription quota. Rate limit: N/A. Status: UNVERIFIED / UNSUPPORTED.
- **ChatGPT & Codex:** No official, documented API to read ChatGPT Plus/Pro/Team subscription quotas or reset times ([OpenAI Rate Limits](https://platform.openai.com/docs/guides/rate-limits)). Admin Usage API (`/v1/organization/usage/completions`) and response headers report developer API consumption only ([OpenAI Usage API](https://platform.openai.com/docs/api-reference/usage)). `~/.codex/` (`auth.json`, `config.toml`) stores local credentials and settings, not quotas. Scraping or calling private endpoints with web session tokens breaches ToS §2(c) ([OpenAI Terms of Use](https://openai.com/policies/terms-of-use)). Auth: `sk-admin-...` for API only. Rate limit: N/A. Status: UNVERIFIED / UNSUPPORTED.
- **Gemini:** No official API or CLI to read Google One AI Premium (Gemini Advanced) consumer quotas. Google AI Studio and Vertex developer APIs track project quotas via Google Cloud Quotas API (`cloudquotas.googleapis.com`), but successful 200 responses return no remaining-quota headers; only 429 returns `retryDelay` ([Gemini API Rate Limits](https://ai.google.dev/gemini-api/docs/rate-limits), [Cloud Quotas API](https://cloud.google.com/docs/quotas)). No local CLI quota files exist. Scraping violates Google ToS ([Google Terms of Service](https://policies.google.com/terms)). Auth: GCP OAuth for API only. Status: UNVERIFIED / UNSUPPORTED.
- **Cursor:** No official API to query individual fast request quotas or reset times ([Cursor Docs](https://docs.cursor.com/)). Admin API (`/teams/daily-usage-data`) serves Enterprise/Teams only ([Cursor API](https://cursor.com/docs/api)). `state.vscdb` caches session tokens and agent history, while quotas are enforced server-side ([VS Code Storage](https://code.visualstudio.com/api/references/vscode-api)). Reverse-engineering private endpoints (`cursor.com/api/usage`) breaches ToS ([Cursor Terms of Service](https://www.cursor.com/terms-of-service)). Auth: None public. Rate limit: N/A. Status: UNVERIFIED / UNSUPPORTED.

## 2. Mica / Acrylic (`DWMWA_SYSTEMBACKDROP_TYPE`) & Blur Alternatives
- **Compatibility with ROQA:** Does NOT work on ROQA's notch/dock window architecture:
  - `WS_EX_LAYERED`: System backdrops are suppressed/ignored on layered windows ([DWM Backdrop Enum](https://learn.microsoft.com/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)). Backdrops require extending the frame via `DwmExtendFrameIntoClientArea` with `WS_EX_NOREDIRECTIONBITMAP`.
  - Non-activating (`WS_EX_NOACTIVATE`): Mica automatically falls back to a neutral solid/opaque color when the window is inactive/unfocused ([Mica Material](https://learn.microsoft.com/windows/apps/design/style/mica)). Because ROQA windows never activate, Mica remains permanently opaque. Acrylic (`DWMSBT_TRANSIENTWINDOW`) survives inactive focus ([Acrylic Material](https://learn.microsoft.com/windows/apps/design/style/acrylic)).
  - Region-shaped (`SetWindowRgn`): Window regions disable hardware DWM frame compositions. Shaping must be done via DirectComposition alpha masking.
  - OS Requirement: `DWMWA_SYSTEMBACKDROP_TYPE` requires Windows 11 Build 22621 (22H2)+ ([DWM Window Attributes](https://learn.microsoft.com/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)).
- **Cheaper Documented Blur Alternative:** None. `DwmEnableBlurBehindWindow` has been non-functional and deprecated since Windows 8 ("doesn't result in the blur effect", [DwmEnableBlurBehindWindow](https://learn.microsoft.com/windows/win32/api/dwmapi/nf-dwmapi-dwmenableblurbehindWindow)). `SetWindowCompositionAttribute` is undocumented/unsupported. `Windows.UI.Composition` backdrop brushes add substantial GPU/compositor overhead.

## 3. Caps Lock & Num Lock Detection (No Global Hooks or Polling)
- **Documented Events:** Windows provides NO system-wide broadcast event or window message when lock keys toggle ([Keyboard Input](https://learn.microsoft.com/windows/win32/inputdev/about-keyboard-input)).
- **Raw Input (`RIDEV_INPUTSINK`):** `RegisterRawInputDevices` with `RIDEV_INPUTSINK` receives background `WM_INPUT` globally ([RAWINPUTDEVICE](https://learn.microsoft.com/windows/win32/api/winuser/ns-winuser-rawinputdevice)). However:
  1. It constitutes system-wide input monitoring (intercepts every keystroke in every app), triggering AV/EDR heuristics and violating ROQA standing integrity rules.
  2. UIPI drops raw input from elevated processes to non-elevated sinks ([UIPI Messages](https://learn.microsoft.com/windows/win32/winmsg/about-messages-and-message-queues)).
  3. It reports key transitions, not toggle state; out-of-band toggles desync state.
- **What Windows Uses:** Windows handles lock key state internally inside the kernel input manager (`win32k.sys` / `kbdclass.sys`), updating the internal thread keystate tables directly for features like ToggleKeys ([GetKeyState](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-getkeystate)).

## Recommendations
1. AI Subscription Usage Meter: DROP (no documented consumer APIs; private endpoints/scraping breach ToS; CLI files store no quotas).
2. Mica Backdrop: DROP (permanently falls back to solid color on non-activating windows; incompatible with `WS_EX_LAYERED`).
3. Acrylic Backdrop: DEFER (requires 22H2+, replacing `WS_EX_LAYERED`/regions with `WS_EX_NOREDIRECTIONBITMAP`, and adds compositor overhead).
4. Cheaper Blur Alternative: DROP (no documented alternative exists; `DwmEnableBlurBehindWindow` is deprecated since Win 8).
5. Caps/Num Lock Detection: DROP (no broadcast event; Raw Input sink is global input monitoring blocked by UIPI and ROQA rules).
